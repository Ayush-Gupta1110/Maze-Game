# Assets Directory

Maze Explorer procedurally renders all graphics using high-definition Pygame geometry primitives, neon glows, particle systems, and dynamic canvas rendering.

Audio effects are procedurally synthesized using mathematically generated wave buffers, so the game does not rely on external downloaded image or sound files.

Any custom fonts or textures placed in this directory will be safely loaded if present, with graceful fallbacks to built-in system fonts and vector rendering.
